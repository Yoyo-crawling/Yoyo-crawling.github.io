# 董慕含个人主页

根据战略与行业研究方向简历整理的个人主页，包含个人简介、教育经历、实习经历详情页、项目、技能与荣誉。

## 本地预览

在 PowerShell 中进入本目录后运行：

```powershell
npm.cmd run dev
```

浏览器访问终端显示的本地地址（通常为 `http://localhost:3000`）。

## 正式构建

```powershell
npm.cmd run build
```

## 主要内容位置

- 页面文字与经历：`app/page.tsx`
- 页面样式：`app/globals.css`
- 证件照：`public/profile.jpg`
- 实习详情数据：`app/experience-data.ts`
- 实习详情页面：`app/experience/`
- 下载版简历：`public/resume.pdf`

## 发布前提醒

当前页面包含简历中的邮箱和电话号码。部署到公开互联网前，建议确认是否保留电话号码，并补充希望公开的 GitHub、LinkedIn 或其他社交链接。
